# ROS 2: робототехнические проекты · 2026

Два проекта на ROS 2 Jazzy: восстановление взаимодействия узлов, работа с
геометрией и временем измерений, воспроизводимая симуляция и управление
суставами через `ros2_control`.

| Проект | Что сделано | Результат |
| --- | --- | --- |
| [Интеграция робота, TF2 и воспроизводимая симуляция](robot_integration/README.md) | Исправлены launch, параметры, QoS, namespaces и модель ровера; реализована проверка измерений на их timestamp; настроены Gazebo–ROS bridges и анализ sim/wall time | Работают один и два экземпляра ROS graph; приёмка TF2 проходит в двух namespaces; Gazebo проходит 40 из 40 проверок |
| [Управление 18 суставами через ros2_control](humanoid_control/README.md) | Настроен JointTrajectoryController, реализованы валидация траекторий, расчёт ошибки и удержание измеренной позы | Выполнено neutral → wave → neutral; максимальная наблюдаемая ошибка слежения 0,064 рад, ошибка при завершении 0,040 рад; проверены отмена и measured hold |

В README проектов приведены выполненные изменения, численные результаты,
ссылки на код, отчёты и команды запуска.

## Структура

```text
robot_integration/
  graph_diagnostics/   # ROS graph, launch, параметры, QoS, два робота
  rover_tf2/           # URDF/Xacro, TF2, время измерения
  rover_simulation/    # Gazebo, bridges, сенсоры, sim/wall time
humanoid_control/      # 18 суставов, траектории, отмена и удержание
task01/                # Отдельная работа с ROS interfaces и actions
```

`robot_integration` объединяет материалы прежних `task02`–`task04`,
`humanoid_control` — прежний `task05`. В первом проекте сохранены три
самостоятельных workspace со своими Docker-окружениями.

## Запуск

Нужны Docker и Compose v2. Команды в README рассчитаны на Bash в Linux или
Ubuntu/WSL. Установка ROS 2 на хост не требуется. Подготовка среды и проверка
UID/GID описаны внутри каждого проекта; для Windows также есть
[заметка об окончаниях строк](WINDOWS_WSL.md).

## Основа проектов

Проекты выполнены на учебных стендах курса SHAD ROS 2. Собственный вклад —
диагностика и исправление интеграции, конфигурация контроллеров и bridges,
реализация прикладных функций, регрессионные тесты и эксперименты. Исходные
условия, контракты и сведения о лицензиях сохранены рядом с кодом.

Дополнительная работа: [ROS 2 graph, interfaces and actions](task01/README.md).
